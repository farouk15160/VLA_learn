# Reproducibility evidence and runtime output

The repository retains the three evaluation packets cited by the root README:
the collapsed seed-7 attempt and the two final seed runs. It also retains only
the best checkpoint from each final seed. Intermediate/final snapshots,
duplicate baseline packets, ROS logs, and Matplotlib caches are intentionally
excluded.

New training checkpoints and process logs are written here and ignored unless
explicitly selected as reproducibility evidence.
